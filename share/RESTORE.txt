OmaBackups — boot this USB to restore
=====================================

Firmware boot menu → this USB.

Limine shows one entry, “Rescue Disk”. That boots the real Omarchy
installer environment and starts a text wizard:

  1. Unlock the backup (the password you set when you formatted this USB)
  2. Pick a restore point (date)
  3. Pick the destination disk — every disk is listed, including
     internal drives and installer sticks. You choose.
  4. Type the disk name, then YES

That wipes the destination permanently and copies the snapshot so the
machine unlocks LUKS and logs in as the same user.

The ESP (OMABOOT) and rescue partition (OmaRescue) are not encrypted.
Backups live on LUKS (OmaBackups; older disks say OMARCHY-TM).

If the wizard is not running:

  mkdir -p /run/oma-usb && mount -L OmaRescue /run/oma-usb
  bash /run/oma-usb/oma-backups/share/rescue-run.sh

  oma-backups mount
  oma-backups snapshots
  oma-backups restore-to-disk /dev/TARGET --snapshot TIMESTAMP --dry-run
  oma-backups restore-to-disk /dev/TARGET --snapshot TIMESTAMP --allow-internal
